# 04 - Retrospectives

เก็บบันทึก **สรุปบทเรียน (Retrospective)** หลังจบแต่ละ phase, sprint หรือ milestone ของโปรเจกต์ เช่น

- สิ่งที่ทำได้ดี (What went well)
- สิ่งที่ควรปรับปรุง (What to improve)
- Action item ที่จะนำไปปรับใช้ในรอบถัดไป

ใช้ข้อมูลประกอบจากผลการทดสอบใน [[../03-testing/02-test-result/index|02-test-result]] และความเคลื่อนไหวใน [[../05-log/index|05-log]] เพื่อให้การสรุปมีหลักฐานอ้างอิง

## เอกสารในโฟลเดอร์นี้

- [[requirements-phase-retro-v1|Requirements Phase Retro v1]] — สรุปบทเรียนจากเฟส requirements-gathering/backlog-creation (สร้าง backlog v1 + 2 รอบ refinement ตาม feedback ของ Touch) เฟสแรกที่จบจริงของโปรเจกต์นี้ — อิงหลักฐานจาก [[../05-log/index|05-log]] เพราะยังไม่มี test result ให้อ้างอิง (โปรเจกต์ยังไม่มีโค้ด)
