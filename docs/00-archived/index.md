Week 3 (UX + Persona + Journey Map) ถูกทำขึ้น **สองชุดคู่ขนานคนละ worktree** โดยไม่รู้กัน — ชุดที่ถูกเลือกเป็นหลักคือชุดที่อยู่ใน [[../01-requirements/01-spec/index|01-spec]] (persona 5 ตัว ฟ้า/ต้น/ป้าน้อย/เบียร์/คุณแอน + journey map พร้อม Mermaid) เพราะครอบคลุมทั้ง `01-requirements` และ `02-design` และวางไฟล์ตรงตามกฎโครงสร้างเอกสารของ vault นี้
