DATA MODEL · §4.2 · STATE MACHINE

สถานะโต๊ะ — ไม่มีปุ่มให้กด

โต๊ะไม่มีคอลัมน์ status ในตาราง สถานะทั้งหมดคำนวณสดจาก VIEW ที่มองว่ามี table_session เปิดค้างอยู่หรือไม่ ผลคือไม่มีอะไรให้ UPDATE จึงไม่มี endpoint เปิดหรือปิดโต๊ะ กติกา BR 11 จึงถูกบังคับด้วยโครงสร้าง ไม่ใช่ด้วยความตั้งใจของคนเขียนโค้ด

STRUCTURAL ENFORCEMENT

ทำไมถึงกดผิดไม่ได้

  • ไม่มีคอลัมน์ status ใน shop_table — สถานะมาจาก table_status_v ที่ LEFT JOIN หา session ที่ยังเปิดอยู่
  • ไม่มีอะไรให้ UPDATE จึงไม่มี endpoint เปิดหรือปิดโต๊ะให้เรียกตั้งแต่แรก
  • transition ที่ผิดกฎถูกกันด้วยโครงสร้าง ไม่ใช่ด้วยข้อตกลงระหว่างทีม

ONE WAY BACK

ทางเดียวที่โต๊ะกลับเป็นว่าง

  • ปิดบิล ซึ่งไปปิด table_session ให้เป็น closed — US-19 เท่านั้น
  • โต๊ะที่มีบิลเปิดค้าง ปลดระวางไม่ได้ ต้องปิดบิลก่อน ไม่งั้นได้ 409 TABLE_HAS_OPEN_BILL
  • โต๊ะที่ปลดระวางแล้วเปิด session ใหม่ไม่ได้ ลูกค้าที่สแกน QR เดิมต้องได้ข้อความที่อ่านเข้าใจ

FIDELITY

ต่างจากต้นฉบับตรงไหน

  • วาดมือ — extractor พังกับ state ที่ตั้งชื่อเป็นภาษาไทย
  • ต้นฉบับไม่มี start node ผมเติมให้เพราะตารางระบุว่าแอดมินเป็นคนสร้างโต๊ะ
  • transition ต้องห้าม 5 ข้อจากตารางใต้แผนภาพ ยุบเป็นกล่องเดียวตามที่ type reference สั่ง ไม่วาดเป็นเส้นกากบาท
