เอกสารเทียบระบบจริง

vault เอกสารกับรีโปโค้ดถูกแยกกันตั้งแต่ 23 ส.ค. ทุกชั้นของ SDLC จึงเลื่อนออกจากของจริงคนละระยะ ภาพนี้บอกว่าชั้นไหนตรงแล้ว ชั้นไหนเพิ่งถูกดึงกลับมาตรงวันนี้ และชั้นไหนเคยเป็นคอขวด

งานวันนี้

สามบล็อกที่ลงมือ

  • ดึง US-53 แดชบอร์ดวิเคราะห์ และ US-54 เข้าสายหลัก หลังค้างบน branch แยก
  • sync เอกสารตามโค้ด: ข้อมูล 29 ตาราง · API 54 route 71 method · เพิ่มหน้าจอ A-08 และ A-09
  • เติมชั้นทดสอบด้วยผลจริง พร้อมคำตัดสิน demo ผ่านแบบมีเงื่อนไข เปิดร้านจริงยังไม่ผ่าน
  • สร้างหน้ารายงานยอดขาย A-09 ปิด US-25 พร้อมเทสใหม่ 33 เคส
  • เทสทั้งชุดหลังรวมงาน 301 เคส ผ่านหมด typecheck และ lint สะอาด

ช่องว่างที่ปิดแล้ว

เอกสารเคยบอกผิด

  • ข้อมูล 21 ตาราง ของจริง 29
  • API 35 endpoint ของจริง 54 route 71 method
  • เทส เอกสารบอกยังไม่รันสักเคส ของจริงผ่าน 268 เคส
  • งานย่อยบอกยังไม่เริ่ม ของจริงสร้างเกือบครบเฟส 0
  • ช่องทางเคาน์เตอร์ เอกสารบอกยังไม่เปิด ของจริงใช้ได้ครบวง

ต้องคิดต่อ

รอคนตัดสิน

  • บิลที่ยอดเหลือศูนย์ปิดไม่ได้เลย โต๊ะจึงปลดไม่ได้ตามไปด้วย ระดับ S1 ยังเปิดค้าง
  • สถานะรอเสิร์ฟที่เกณฑ์รับงานติ๊กว่าเสร็จแล้ว ไม่มีอยู่ในโค้ดแม้แต่จุดเดียว
  • งานล้างชื่อเล่นลูกค้าเมื่อครบเก้าสิบวันไม่มีจริง เป็นความเสี่ยงตรงเรื่องข้อมูลส่วนบุคคล
  • เวลาปิดร้านที่ใช้ตัดขอบวันธุรกิจ ยังไม่มีหน้าตั้งค่า แก้ได้ทาง SQL เท่านั้น
  • ฟังก์ชันดูรายละเอียดบิลเขียนไว้แล้วแต่ไม่มีทางเรียก เป็นโค้ดตาย ต่อสายหรือลบทิ้ง
  • ยังไม่มีการสำรองฐานข้อมูลอัตโนมัติ และไม่เคยทดสอบกู้คืนจริงสักครั้ง
