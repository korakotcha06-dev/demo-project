## ข้อตกลงของโฟลเดอร์นี้

- **ตั้งชื่อ** `<เรื่อง>-v<n>` — ขึ้นเลขใหม่เมื่อเนื้อหาเปลี่ยนจนอ่านแล้วได้ข้อสรุปคนละอย่าง ไม่ใช่แค่ขยับตำแหน่งกล่อง · **ห้ามลบเวอร์ชันเก่า** ให้ทำเครื่องหมายว่าถูกแทนที่ในตารางด้านบน
- **ฟอนต์ไทยต่ำกว่า 10px อ่านไม่ออก** เพราะสระบนล่างกับวรรณยุกต์ทับกัน — ป้ายขนาด 8px ในภาพจึงเป็นอังกฤษกับตัวเลขล้วนโดยตั้งใจ ไม่ใช่ความมักง่าย
- **แผนภาพไม่ใช่แหล่งความจริง** เอกสาร markdown คือแหล่งความจริง ภาพเป็นของที่ derive มา
- ยังไม่มีภาพของ 4 บล็อกใน [[../../../01-requirements/01-spec/ux-journey-map-v1\|UX Journey Map v1]] ที่เขียนด้วย grammar `journey` เพราะเครื่องมือที่ใช้แปลงไม่รองรับ และไม่ควรแปลงเป็นชนิดอื่นเพราะจะบิดความหมาย
