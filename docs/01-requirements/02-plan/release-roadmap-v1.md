# Release Roadmap v1 — ระบบสั่งอาหารด้วย QR Code

> แตกมาจาก backlog ใน [[../01-spec/product-backlog-v1|01-spec/product-backlog-v1]] จัดกลุ่ม user story เป็น phase ตามลำดับที่ควร ship จริง
> จัดทำโดย: XAVIER · วันที่ 2026-08-02

กลับไปที่ [[index|02-plan]]

หลักการจัดลำดับ: Phase 0 คือ MVP บางที่สุดที่ยังครบ flow หลัก "สแกน QR → ดูเมนู → สั่งออเดอร์ → ออเดอร์ไปถึงครัว/แจ้งเตือน → จ่ายเงินจบบิล" ได้จริงโดยไม่มีพนักงานมารับออเดอร์ที่โต๊ะ ฟีเจอร์เสริม (ตัวเลือกสินค้า, ใบเสร็จ, รายงาน, สมาชิก, หลายภาษา, จ่ายเงินออนไลน์) เลื่อนไป Phase ถัดไปทั้งหมด

---

## Phase 0 — MVP (ต้องมีก่อนเปิดร้านจริง)

เป้าหมาย: ลูกค้านั่งโต๊ะ สแกน QR สั่งเองได้ครบ ไม่ต้องมีพนักงานมารับออเดอร์ที่โต๊ะเลย ครัวเห็นออเดอร์และอัปเดตสถานะได้ แคชเชียร์ปิดบิลได้ แอดมินตั้งเมนู/QR เองได้

| US-03 | จัดการตะกร้าสินค้า | ลูกค้า |

## Phase 1 — เสริมความลื่นไหลของหน้าร้าน (หลัง MVP นิ่งแล้ว)

เป้าหมาย: ลดความคลาดเคลื่อนของออเดอร์ (ตัวเลือก/หมายเหตุ) และเติมเครื่องมือหลังบ้านที่ร้านจริงต้องใช้ทุกวัน (ใบเสร็จ, คืนเงิน, รายงาน)

| ID | เรื่อง | Actor |
|---|---|---|
| US-08 | เลือกตัวเลือกเสริมของสินค้า | ลูกค้า |
| US-09 | ใส่หมายเหตุพิเศษต่อรายการ | ลูกค้า |
| US-17 | ดูประวัติออเดอร์ย้อนหลังของกะ | ครัว/บาร์ |
| US-21 | ออกใบเสร็จ | แคชเชียร์ |
